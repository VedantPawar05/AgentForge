3. HOW TO TEST & REVIEW THE CALCULATOR IN THE WEB APP
--------------------------------------------------------------------------------
1. Open your browser and navigate to:
   http://localhost:3000/dashboard

2. How to access the Live Preview:
   - Option A: Click "Preview" in the left sidebar navigation (under the Infrastructure group).
   - Option B: Navigate to "Tasks" in the sidebar, locate the Calculator task, and click the "Preview" button.
   - Option C: Open the Command Palette by pressing Ctrl+K (or ⌘K) and select "Live Preview".

3. Interactive Testing in the Preview:
   - Arithmetic: Test addition (7 + 8 = 15), subtraction, multiplication (9 × 6 = 54), division.
   - Decimal logic: Test floating point precision (0.1 + 0.2 = 0.3).
   - Percentage (%): Enter 50 and click % -> converts to 0.5.
   - Sign inversion (+/-): Toggle positive/negative values.
   - Clear (AC): Resets state cleanly.
   - Divide-by-Zero Guard: Divide any number by 0 -> displays "Error" cleanly without crash.
   - Attribution: Notice the OpenAI (UI/UX) and Gemini (Logic) attribution tags.
   - Export: Click "↓ Export HTML" to save the standalone calculator file to your machine.
